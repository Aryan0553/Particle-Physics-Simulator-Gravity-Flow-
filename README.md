# Particle Physics Simulation 🎆
An interactive particle physics simulation developed in Python using Tkinter. 
This project visualizes real-time particle motion with gravity, collisions, fading effects, and user-driven interactions, showcasing core concepts of physics-based animation and GUI programming.


## 🚀 simulation

- Real-time particle movement with smooth animation
- Gravity points that attract particles dynamically
- Collision handling with walls and energy loss
- Particle lifespan with fade-out effects
- Mouse and keyboard interactivity
- Optimized update loop targeting ~60 FPS



## 🖱️ Controls

- **Left Click** → Spawn particles  
- **Right Click** → Create gravity point  
- **H** → Toggle help text  
- **C** → Clear all particles  
- **G** → Remove all gravity points  


## 🛠️ Tech Stack

- **Language:** Python  
- **GUI Library:** Tkinter  
- **Concepts Used:**  
  - Physics simulation  
  - Vector math  
  - Event-driven programming  
  - Animation loops
